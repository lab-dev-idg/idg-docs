# 1. مەبەست و چوارچێوەی نەخشەڕێگا — Purpose & Horizon Architecture

The **Strategic Roadmap Domain** (`roadmap/`) defines the multi-horizon planning frameworks, prioritization mechanics, dependency trees, and change-control protocols governing the long-term evolution of Iraq Digital Gateway (IDG).

Rather than fabricating arbitrary calendar deadlines, IDG utilizes an **Architecture Horizon Planning Model (مۆدێلی پلاندانانی ئاسۆی تەلارسازی)** anchored on capability readiness, dependency gates, and strategic horizons culminating in **Vision 2030**.

```
                      ┌───────────────────────────────────────┐
                      │    HORIZON 3: LONG-TERM / VISION 2030 │
                      │  Sovereign Digital Ecosystem & AI Mesh│
                      └───────────────────▲───────────────────┘
                                          │
                      ┌───────────────────┴───────────────────┐
                      │    HORIZON 2: MEDIUM-TERM HORIZON     │
                      │  Portfolio Expansion (Product 002+)   │
                      └───────────────────▲───────────────────┘
                                          │
                      ┌───────────────────┴───────────────────┐
                      │    HORIZON 1: NEAR-TERM FOUNDATION    │
                      │  Core Platform Hardening & AGI Prod 001│
                      └───────────────────────────────────────┘
```

# 3. حوکمڕانی و پێداچوونەوە — Roadmap Governance Model

- **Review Cadence**: Quarterly horizon calibration by the Enterprise Architecture Council.
- **Dependency Gate Rule**: No Horizon 2 or 3 initiative may commence until all upstream Horizon 1 architectural dependencies are validated and operational.
