# 2. قۆناغەکانی گەشەی بەرهەم — Product Horizon Milestones

### ئاسۆی 1: چەسپاندن و سەروەری بەرهەمی 001 — Horizon 1: AI Gate Iraq Hardening
- Launch production AI Gate Iraq console (`aigate.iq`) with full trilingual parity.
- Deploy OpenAI-compatible `/v1/chat/completions` and `/v1/embeddings` API endpoints.
- Establish sovereign vector RAG with hybrid lexical/semantic retrieval for Kurdish Sorani, Arabic, and English.
- Implement fine-grained tenant usage analytics, token metering, and API key management.

### ئاسۆی 2: فرەبەرهەمی و خزمەتگوزارییە پەیوەستەکان — Horizon 2: Vertical Portfolio Incubation
- Expand AI Gate Iraq with multimodal voice/audio inference and live streaming channels.
- Incubate enterprise workflow automation modules (`Product 002+`) on top of shared IDG platform services.
- Deploy self-service enterprise document intelligence pipelines.

### ئاسۆی 3: ژینگەی ژیریی سەروەری تەواو — Horizon 3: Autonomous Cognitive Ecosystem (Vision 2030)
- End-to-end multi-agent orchestration for complex institutional workflows.
- Sovereign fine-tuned foundational models optimized natively for Iraqi dialectal Arabic and Kurdish varieties.
