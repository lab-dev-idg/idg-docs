# 1. مەبەست و کایەکانی دۆمەینی براند — Purpose & Brand Domain Scope

The **Brand Documentation Domain** (`brand/`) defines the complete institutional design, visual language, tonal voice, color science, typography, and iconography architecture of Iraq Digital Gateway (IDG) and its product portfolio.

It bridges corporate strategy and digital implementation, ensuring that all digital interfaces, public surfaces, enterprise portals, and documentation artifacts convey sovereign authority, clarity, and precision.

# 3. پەیوەندی بە سیستەمی دیزاینەوە — Relationship to Design System

While `design-system/` specifies the concrete CSS tokens (`design-tokens.md`) and React components (`components.md`), the `brand/` domain establishes the overarching design philosophy, aesthetic standards, and brand rules that govern token values and component semantics.
